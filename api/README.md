# API — Minisúper Teresita

API REST en Laravel del proyecto del curso ISW-621 Web II.

La documentación completa (arquitectura hexagonal, puesta en marcha, flujo de ramas, convenciones de commits y uso de IA) está en el [README principal](../README.md).

## Comandos útiles

```bash
composer install
php artisan serve
composer test       # pruebas con Pest
composer lint       # revisa el estilo con Pint, sin cambiar archivos
composer format     # corrige el estilo con Pint
composer analyse    # análisis estático con Larastan
composer openapi    # exporta la documentación a openapi.json
```
