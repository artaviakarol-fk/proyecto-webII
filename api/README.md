# API — Minisúper Teresita

API REST en Laravel del proyecto del curso ISW-621 Web II.

La documentación completa (arquitectura hexagonal, puesta en marcha, flujo de ramas, convenciones de commits y uso de IA) está en el [README principal](../README.md).

```bash
composer install
php artisan serve
vendor/bin/pest
vendor/bin/pint
vendor/bin/phpstan analyse
```
